Sistema de Chamados — F4 Sistemas

📌 Sobre o projeto

Esse é o meu primeiro projeto desenvolvido por iniciativa própria, fora das atividades propostas pelo curso de Análise e Desenvolvimento de Sistemas.

A ideia surgiu a partir das minhas experiências profissionais com atendimento e suporte. Pensei em como poderia transformar algumas dessas experiências em um projeto de programação e, a partir disso, surgiu a ideia de criar um sistema simples para abertura e consulta de chamados.

O projeto foi desenvolvido totalmente em Python utilizando os conhecimentos que tenho atualmente. Como ainda estou no processo de aprendizado, a ideia é continuar trabalhando nele conforme eu aprender novas ferramentas, conceitos e maneiras de resolver os problemas.

Por isso, esse projeto não pretende ser uma versão final. Quero que ele acompanhe minha evolução na programação e que, no futuro, eu possa voltar ao código e melhorar aquilo que hoje ainda estou aprendendo.

🐍 Tecnologias utilizadas

* Python

⚙️ Funcionalidades atuais

* Abertura de novos chamados;
* Identificação do solicitante;
* Seleção da área responsável pelo atendimento;
* Separação dos chamados por área:
  * Cadastros;
  * ERP;
  * Infraestrutura;
  * Acessos;
* Limitação da descrição do problema a 100 caracteres;
* Identificação dos chamados por número;
* Consulta de chamados;
* Consulta do status do chamado;
* Validação das opções informadas pelo usuário.

🚀 Próximos passos

Conforme eu for aprendendo novos conceitos durante o curso e meus estudos, pretendo implementar novas funcionalidades e melhorar a estrutura do projeto.

🎯 Por que fiz esse projeto?

A ideia desse projeto foi criar algo além das atividades do curso, utilizando Python para desenvolver uma solução baseada em situações que já encontrei nas minhas experiências profissionais.

O projeto também será atualizado conforme eu adquirir novos conhecimentos, permitindo implementar novas funcionalidades e melhorar a estrutura do sistema ao longo do tempo.
